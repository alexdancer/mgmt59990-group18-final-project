# Generative AI use disclosure

The group used generative AI tools to support brainstorming, architecture and diagram ideas, AWS CLI and IAM troubleshooting, code and SQL drafting, test suggestions, documentation editing, and presentation development.

AI output was treated as a draft rather than project evidence. The group independently:

- executed the AWS Console and CloudShell steps;
- checked S3 objects, Glue tables and job runs, Athena query status and outputs, SageMaker metrics, and QuickSight datasets and visuals;
- corrected resource paths, permissions, workgroup behavior, and commands when actual AWS results differed from suggestions;
- reviewed and modified the Python, SQL, documentation, diagrams, and presentation content;
- reconciled reported counts and metrics against saved outputs; and
- approved the final architecture decisions and written claims.

No AWS access keys or passwords were provided to or stored by the project repository.
